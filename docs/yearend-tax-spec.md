# 연말정산 환급 예상 계산기 명세 초안 (2026년 귀속, 2027년 1월 정산)

> 상태: 초안. 민간 계산기 2곳(taxcut.kr, jptcalc.kr) 기준 2차 정리. **계산에 쓰는 모든 수치는 출시 전 국세청·법령 원문으로 대조 필수.**
> 출처: [T] https://www.taxcut.kr/year-end-tax/guide · [J] https://www.jptcalc.kr/blog/posts/year-end-tax-2026-changes.html

## 1. 계산 흐름 (MVP)
```
근로소득금액   = 총급여 − 근로소득공제(한도 2,000만)
과세표준       = 근로소득금액 − 인적공제 − 연금·4대보험료 − 카드 등 소득공제 − 주택자금
산출세액       = 과세표준 × 세율 − 누진공제   (6~45%, 8구간)
결정세액       = 산출세액 − 근로소득세액공제 − 자녀 − 연금계좌 − max(특별세액공제+월세, 13만 표준) − 기타
지방소득세     = 결정세액 × 10%
환급(납부) 예상 = 기납부세액(원천징수 합계) − (결정세액 + 지방소득세)
```

## 2. 확인된 수치
| 항목 | 값 | 출처 |
|---|---|---|
| 기본공제 | 1인 150만 | T,J |
| 경로우대(70+) / 장애인 | 100만 / 200만 | T |
| 자녀세액공제 | 1명 25만, 2명 55만, 3명~ +40만/인 | T,J |
| 출산·입양 | 첫째 30만, 둘째 50만, 셋째~ 70만 | T |
| 카드 최저사용 | 총급여 25% 초과분 | T,J |
| 카드 공제율 | 신용 15%, 체크·현금 30%, 전통시장·대중교통 40%, 도서공연(7천 이하) 30% | T,J |
| 카드 기본한도(7천 이하) | 300 / 자녀1 350 / 자녀2+ 400만 | T,J (2026 신설) |
| 카드 기본한도(7천 초과) | 250 / 275 / 300만 | T,J |
| 카드 추가한도 | 전통시장+대중교통 200만, 문화체육 포함 300만 | J |
| 보장성보험 | 12% (장애인 15%), 한도 100만 | T |
| 의료비 | (지출 − 총급여 3%) × 15%, 일반 부양가족 700만 한도 | T |
| 교육비 | 15%, 초중고 300만, 대학 900만, 본인 무한 | T |
| 월세 | 5,500만 이하 17%, ~8,000만 15%, 한도 1,000만 | T,J |
| 연금저축/IRP | 5,500만 이하 15%, 초과 12%, 합산 900만(연금저축 600만) | T |
| 표준세액공제 | 13만 | T |
| 지방소득세 | 10% | J |

## 3. 미확인, 원문에서 채울 것
- 근로소득공제 구간 공식
- 기본세율 8구간 과세표준·누진공제액 표
- 근로소득세액공제 구간 공식과 총급여별 한도
- 부녀자·한부모 추가공제

## 4. 출처 간 불일치 (원문 확인 필요)
1. 자녀세액공제 대상 나이: T는 8세 이상 유지, J는 2026 귀속부터 9세 이상(2017년생 제외)
2. 카드 한도 증액 대상 자녀: T는 18세 미만, J는 20세 이하+소득요건

## 5. MVP 범위 제안
- 입력: 총급여, 기납부세액, 부양가족(배우자·자녀 나이·부모), 카드 사용액(수단별), 보험료·의료비·교육비·월세·연금저축 금액
- 제외(v2): 주택자금, 기부금 세부, 중소기업 취업자 감면, 결혼세액공제
- 계산 모듈은 순수 TS 함수 + 국세청 예시 케이스 기반 단위 테스트
