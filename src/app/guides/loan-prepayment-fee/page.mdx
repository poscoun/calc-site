# 중도상환수수료 계산법, 1억 갚으면 얼마? (2025년 개편 후 요율)

대출을 만기 전에 갚으면 중도상환수수료가 붙습니다. 2025년 1월 13일 이후 새로 받은 대출부터는 은행이 **실제 드는 비용만** 수수료로 받을 수 있게 바뀌어, 주택담보대출 요율이 절반 이하로 내려갔습니다.

## 계산식

> 중도상환수수료 = 상환금액 × 수수료율 × 잔존일수 ÷ 대출기간

- **잔존일수**: 상환일부터 만기일까지. 대출기간이 3년을 넘으면 대출일로부터 3년째 되는 날을 만기로 봅니다.
- **대출기간**: 대출일부터 만기 전날까지. 3년이 넘으면 3년(1,095일)으로 봅니다.
- 그래서 **대출받고 3년이 지나면 수수료가 0원**입니다. 3년이 가까워질수록 수수료도 줄어듭니다.

## 1억 원을 갚을 때 수수료

30년 주택담보대출에서 1억 원을 중도상환하는 경우입니다.

| 상환 시점 | 요율 | 중도상환수수료 |
|---|---|---|
| 대출 1년 후 (잔존 730일) | 0.55% (변동) | **366,666원** |
| 대출 1년 후 (잔존 730일) | 0.75% (고정) | 500,000원 |
| 대출 2년 6개월 후 (잔존 183일) | 0.55% (변동) | 91,917원 |
| 대출 3년 후 | | **0원** |
| 대출 1년 후, 개편 전 요율 | 1.20% (변동) | 800,000원 |

요율은 KB국민은행이 2026년 1월 1일 이후 대출에 적용하는 값입니다(부동산담보 변동 0.55%, 그 외 0.75%). 은행과 대출 시점마다 다르므로 대출 약정서나 은행 누리집에서 확인하세요.

## 2025년 개편 전후 평균 요율 (은행권)

금융위원회가 2025년 1월 9일 발표한 은행권 평균입니다.

| 대출 종류 | 개편 전 | 개편 후 |
|---|---|---|
| 주택담보 고정금리 | 1.43% | 0.56% |
| 주택담보 변동금리 | 1.25% | 0.55% |
| 기타담보(전세 등) 고정 | 1.09% | 0.45% |
| 신용대출 고정금리 | 0.95% | 0.12% |
| 신용대출 변동금리 | 0.83% | 0.11% |

신용대출은 요율이 0.1% 안팎이라 수수료가 거의 없습니다. 신용대출 3,000만 원(1년 만기)을 6개월 만에 갚아도 0.11% 기준 16,545원입니다. 2025년 1월 12일 이전에 받은 대출은 예전 요율이 그대로 적용됩니다.

## 수수료가 면제되는 경우

- **대출 후 3년 경과**: 모든 금융회사 공통입니다.
- **매년 일부 상환 면제**: 많은 은행이 부동산담보대출에 대해 매년 최초 대출금의 10%까지는 수수료 없이 갚게 해 줍니다. 2억 원 대출이면 1년에 2,000만 원까지입니다. 쓰지 않은 한도는 다음 해로 넘어가지 않습니다.
- 위 1억 원 상환 예시에서 2,000만 원이 면제되면 수수료는 **293,333원**으로 줄어듭니다.
- 버팀목 전세자금대출 같은 일부 정책대출과 카드론은 수수료가 없습니다.

## 갈아타기(대환)할 때 따져 볼 것

금리가 낮은 대출로 갈아타면 첫해 이자 절감액이 중도상환수수료와 부대비용(인지세, 근저당 설정비 등)보다 큰지 보면 됩니다.

본 사이트 [대출 이자 계산기](/calculators/loan-interest/)로 계산한 예시입니다. 잔액 2억 원, 남은 기간 29년, 원리금균등 상환입니다.

| 구분 | 연 4.5% 유지 | 연 3.8%로 대환 |
|---|---|---|
| 월 납입액 | 1,029,987원 | 949,219원 |
| 첫해 이자 절감 | | **1,396,552원** |
| 남은 기간 총이자 절감 | | **28,106,889원** |
| 중도상환수수료 (대출 1년 차, 0.55%) | | 733,333원 |

첫해에 아낀 이자만으로 수수료를 넘기 때문에, 부대비용이 수십만 원이어도 1년 안에 본전을 찾습니다. 금리 차이가 0.2~0.3%p 정도로 작거나 대출 3년이 거의 다 됐다면, 몇 달 기다렸다 수수료 없이 갈아타는 것이 나을 수 있습니다.
