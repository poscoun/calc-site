# 연금저축·IRP로 연말정산 환급 늘리기 (2026년 귀속)

연말정산에서 **지금 당장 바꿀 수 있는 거의 유일한 항목**이 연금계좌 세액공제입니다. 카드 사용액이나 의료비는 이미 쓴 돈이지만, 연금저축과 IRP는 **12월 31일까지 입금한 금액**이면 올해 공제에 들어갑니다.

## 한눈에 보기

| 구분 | 내용 |
|---|---|
| 공제 한도 | 연금저축 연 600만 원, 연금저축 + IRP 합산 연 900만 원 |
| 공제율 | 총급여 5,500만 원 이하 15%, 초과 12% |
| 최대 공제액 | 135만 원 (15%) 또는 108만 원 (12%) |
| 지방소득세 | 공제액의 10%가 추가로 줄어듦 |
| 마감 | 2026년 12월 31일 입금분까지 |

연금저축만으로는 600만 원까지만 인정되고, 900만 원을 다 채우려면 **IRP에 300만 원 이상**을 넣어야 합니다.

## 실제로 환급이 얼마나 늘까?

본 사이트 [연말정산 계산기](/calculators/yearend-tax/)로 직장인 두 명을 계산해 봤습니다. 다른 조건은 그대로 두고 연금 납입액만 바꿨습니다.

**총급여 5,000만 원** (기납부세액 250만 원, 국민연금 225만 원, 건강·고용보험 230만 원, 카드 2,000만 원 사용)

| 연금 납입 | 예상 환급액 | 늘어난 금액 |
|---|---|---|
| 없음 | −5만 9,125원 (추가 납부) | - |
| 연금저축 600만 원 | 93만 875원 | **+99만 원** |
| 연금저축 600 + IRP 300만 원 | 142만 5,875원 | **+148만 5천 원** |

**총급여 8,000만 원** (기납부세액 700만 원)

| 연금 납입 | 예상 환급액 | 늘어난 금액 |
|---|---|---|
| 없음 | 1만 3,200원 | - |
| 연금저축 600 + IRP 300만 원 | 120만 1,200원 | **+118만 8천 원** |

900만 원을 넣으면 1년 만에 13.2~16.5%의 수익을 확정으로 받는 셈입니다.

## 넣기 전에 꼭 알아둘 점

- **55세 이후 연금으로 받는 돈**입니다. 중간에 해지하면 공제받은 금액에 대해 기타소득세 16.5%를 다시 냅니다. 생활비가 빠듯하다면 연금저축 일부만 넣는 게 낫습니다.
- **결정세액이 0이면 효과가 없습니다.** 이미 낼 세금이 거의 없는 분(대략 총급여 2,500만 원 이하)은 공제를 받아도 돌려받을 세금이 없습니다. 계산기에서 결정세액을 먼저 확인하세요.
- **12월 31일이 주말이면** 은행·증권사 이체 마감이 앞당겨질 수 있습니다. 넉넉하게 12월 중순까지 넣는 걸 권장합니다.
- 연금저축은 증권사 계좌로 만들면 ETF 투자가 가능해 운용 자유도가 높습니다.
