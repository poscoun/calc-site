# 사이트 소개

돈돈 계산기는 월급쟁이가 자주 궁금해하는 돈 계산을 **숫자 몇 개만 넣으면** 바로 확인할 수 있게 만든 무료 계산기 사이트입니다. 결과 금액만 보여 주지 않고, 그 금액이 **왜 나오는지 계산 과정까지** 함께 보여 드리는 것을 목표로 합니다.

## 제공하는 계산기

- <Link href="/calculators/yearend-tax/">연말정산 환급 예상 계산기</Link>: 2026년 귀속 공제 항목을 반영한 환급액
- <Link href="/calculators/net-salary/">연봉 실수령액 계산기</Link>: 2026년 4대보험 요율과 근로소득 간이세액표
- <Link href="/calculators/severance-pay/">퇴직금 계산기</Link>: 평균임금, 퇴직소득세, 세후 수령액
- <Link href="/calculators/unemployment-benefit/">실업급여 계산기</Link>: 2026년 상한·하한액으로 하루 금액과 총액
- <Link href="/calculators/loan-interest/">대출 이자 계산기</Link>: 원리금균등·원금균등·만기일시 비교

## 계산 원칙

1. **공개된 법령과 고시를 기준으로 합니다.** 세율, 공제율, 보험료율 같은 수치는 소득세법, 근로자퇴직급여 보장법, 보건복지부 고시 등 출처를 코드에 함께 기록합니다. 출처끼리 다르면 임의로 정하지 않고 확인될 때까지 반영을 미룹니다.
2. **원 단위까지 정확하게 계산합니다.** 소수점 오차가 생기지 않도록 정수로 계산하고, 법령이 정한 절사 규칙(10원 미만 버림 등)을 따릅니다.
3. **계산 결과를 자동으로 검증합니다.** 모든 계산 로직에는 법령 예시와 공개 자료의 값으로 만든 자동 테스트가 붙어 있고, 테스트를 통과해야만 사이트에 반영됩니다.
4. **입력값을 저장하지 않습니다.** 계산은 모두 이용자의 브라우저 안에서 이뤄지고, 입력한 숫자는 어디에도 전송되지 않습니다.

## 가이드 작성 방식

<Link href="/guides/">돈 계산 가이드</Link>의 글은 AI 도구로 초안을 만든 뒤, 글에 나오는 모든 금액을 사이트 계산기 코드로 다시 계산하고 운영자가 검수한 다음 게시합니다. 법령이 바뀌면 글과 계산기를 함께 고칩니다.

## 알려 드립니다

계산 결과는 공개된 법령과 고시를 바탕으로 한 추정치이며 세무·법률 자문이 아닙니다. 실제 금액은 회사의 급여 담당자, 금융기관, 국세청 안내로 확인하세요.
